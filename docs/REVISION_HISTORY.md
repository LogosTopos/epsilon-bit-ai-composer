## 轮次 1 — 标准版:变速叙事实验(`cca65f3`)

**背景**:此前作品(深渊回响/无名之渊)均为固定 BPM 匀速行进,机械感明显。本曲实验 **BPM 可变**。

**设计**:
- Tempo map:`引子 96 → 主题 132 → B 段 144 → rit. 132→120(喘息)→ 高潮 138 → 冲刺 142→148 逐小节加速 → 重击骤停`
- 战斗乐理:A 小调 i-VI-III-VII 驱动;4/4;鼓组(八分脉冲/backbeat/切分底鼓);低音八分 riff;切分/十六分冲刺旋律;定音鼓滚奏

**技术要点**:
- `set_tempo` 事件按小节位置写入 meta 轨(**发现并修复 meta 轨错位 bug**:`tracks[0]` 字典索引指向钢琴轨而非 meta 轨,tempo 事件全部写错轨)
- 多声部叠加削波:重击处 FluidSynth 内部削波 → **渲染 gain 0.8(零触顶)+ MP3 端 alimiter 防削波**

**验证**:BPM 序列读回与设计一致;动态曲线引子低→高潮峰→骤停。

## 轮次 2 — 完整版:4 分钟结构延拓(`98e3aef`)

**背景**:标准版结构短促,和声循环机械(A 段 Am-F-C-G 原样 ×6),无织体对比,重击后无余韵。

**设计**(116 小节 ≈ 3:52):

```
引子(96) → A1(132 呈示)→ A2(132, E7 属色彩 G#)
→ B(144, E7 属驻留 4 小节)→ 插部(120 减速对比:拨弦+卡农+无鼓留白)
→ 高潮(138 全奏+铜管六度对位)→ 冲刺(142→150)→ 重击 → 余韵(72 动机回声)
```

**复杂度提升手段**:
- 和声功能化:E7 属和弦(G# 半音色彩)、属驻留、插部 i-iv-V7-i 卡农、高潮 F-G-Am 强力收束
- 织体对比:插部切 Pizzicato(program change)、前 8 小节无鼓、低音二分长音
- 对位:高潮铜管以主旋律下方六度平行副旋律
- 节奏:8 小节鼓 fill、轻律动恢复、滚奏 break 衔接
- 动机贯穿:引子预示碎片 → 主题 → 插部变形 → 余韵回声
- 动态:CC11 乐句级节点(每 4 小节)

**验证**:20 dB 动态跨度(引子 -36.5 → 高潮 -23.0 → 余韵 -43.5);插部回落、余韵衰减证明对比生效。

## 轮次 3 — 转场平滑化(`0e4ab91`)

**背景**:用户反馈"转场不自然,快鼓点被停止、音色切入切出突兀"。

**六处转场修复**:

| 转场 | 手段 |
|---|---|
| 引子→A | 节奏先现(bar8 末轻 HH+kick 预兆)+ 前 2 小节无军鼓渐进 |
| A2→B | fill16:末 2 拍十六分 HH 滚入(速度+密度换挡预热) |
| B→插部(最突兀) | 鼓抽离斜坡(bar55 抽稀→bar56 只剩 HH+kick)+ CC11 108→92→58 + 拨弦 program 在最后一击后切换 |
| 插部→高潮 | 滚奏 break + 末拍低音垫 + 弦乐音色滚奏中提前切回 + 吉他弱档 |
| 高潮→冲刺 | fill 衔接 |
| 重击→余韵 | 延音重叠 + tempo 150→96→72 渐进冷却(原为两倍速突降) |

**验证**:2 秒窗口 RMS 扫描,所有转场呈斜坡形态无跳变(B→插部 `-20.7→-23.4→-28.8→-33.4`)。

## 轮次 4 — 和谐性审查:副旋律归位(`559b479`)

**背景**:逐小节核对旋律与和弦、铜管对位、声部堆叠。

**审查结论**:
- 旋律层无错误音(18 处"碰撞"全为调内自然音级:Am 的 6 音 F、挂四、E7 的 b13)
- **铜管平行六度在非和弦音上"双重偏移"产生真实不协和**(bar74 G 上 G#5/#5、bar75 Am 上 A#4/b9、bar83 D#5、bar90 G#5)
- 低频三层堆叠(低音/吉他/合唱同音高同节奏):255 次低音-吉他同音

**修复**:`counter_melody()` 归位逻辑——副旋律音与和弦冲突时就近(±2 半音)取和弦音。

**验证**:副旋律冲突 0 处。

## 轮次 5 — 2:17 爆发点分层进入(`559b479`)

**背景**:用户反馈 2:17 开始的小节别扭(经 tempo map 计算 = bar 73 高潮第一小节)。

**成因**:8 个声部 + crash 同刻砸下;滚奏着陆过重;低频堆叠起点。

**修复**:
- **织体分层**:bar73 骨架(鼓/低音/弦乐/旋律/铜管弱档 70)→ bar74 吉他 → bar75 合唱 → bar76 全满
- **和声预挂**:bar72 滚奏后半先落 F 低音长音,末拍预垫 A2→F2,爆发落在已准备的和声上

**验证**:bar73 区域 0.5s 窗口 RMS 呈连续渐强斜坡(`-43→-35.7→-29.4→-26.1→-20→-16.4`),无跳变。

## 轮次 6 — 声部分层:低频浑浊/齐奏修复(`d02bd2b`)

**背景**:用户确认修复上一轮审查中的中小型问题(低频浑浊、无层次)。

**修复**——五声部独立音区:

| 声部 | 修复前 | 修复后 | 音区 |
|---|---|---|---|
| 低音 | 根音八分 | 不变 | 41-52 |
| 吉他 | [45,52,57](与低音同度) | 开放五度 [57,64,69] | 53-69 |
| 弦乐 | 根三五 | 不变(保留三音职责) | 53-64 |
| 合唱 | [45,52,57](与吉他同音) | 5-1-3 转位 [64,69,72] | 60-72 |
| 铜管 | 与弦乐逐音同度 | 根+五两音 [57,64] | 53-81 |
| 旋律 | — | — | 76-91 |

引子/余韵 pad 去掉重复根音(110Hz 区仅剩低音 drone)。

**验证**:低音-吉他同音 255→0;合唱-吉他 71→44(长音 vs 短击奏的正常叠置);动态弧线与转场斜坡不变;WAV 零触顶。

## 沉淀的技术规则(可复用)

1. **转场五件套**:节奏先现 / 密度渐进(抽离-恢复)/ 音色提前切换(program change 在无声区)/ 和声预挂 / 速度中间值(150→96→72)
2. **爆发点进入原则**:新段落头 1-4 小节分层叠满(骨架→加层→全满),不瞬间全奏
3. **声部分层原则**:每个声部有专属音区,低频区(110Hz 附近)只允许一个声部;三音职责唯一(弦乐),其他声部用根+五开放排列
4. **平行对位规则**:副旋律冲突音就近归位到和弦音(±2 半音内)
5. **防削波链路**:渲染 gain 0.8 → 检查 WAV 零触顶 → MP3 `volume + alimiter`
6. **验证标准**:tempo map 读回、声部核对、分段 RMS、转场 2s 窗口扫描、副旋律 dissonance 计数、峰值检查
