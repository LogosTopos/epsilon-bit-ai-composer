# 《搜打撤》游戏音频架构 — 母节/子节体系(设计定稿)

> 核心思想(用户指示):以一个**超级高密度的母循环节**(~1min)为素材库,
> 按搜打撤游戏原则派生多种**子节**(每种子节 = 母节的受控改动),
> 并制定**子节间转场规范**——音乐随游戏节奏无缝切换,营造不同氛围/画风。

---

## 1. 架构总览

```
                     ┌─ 强度子节(层数增减,垂直混音)
                     ├─ 密度子节(节奏型变化,水平)
  母节(素材库,~1min) ─┼─ 氛围子节(织体/和声替换)
                     ├─ 情绪子节(音区/音色/移调)
                     └─ 速度子节(BPM 微调)
            转场规范:小节边界 + 力度交叉 + 和声预挂 + 可截断
```

- **母节 = 全部素材的最小完备集**:所有动机(riff/刺刀/Hook)、所有音色层、所有强度档
- **子节 = 母节的"视图"**:不新增音乐素材(除少量过渡元素),只做取舍/变形
- **共享骨架**:所有子节共享和声循环(Em-C-G-D)与 BPM 网格 → 任意顺序切换都和谐

## 2. 母节规格(当前 v6,目标 v7)

| 项 | 现状 v6 | 目标 v7 |
|---|---|---|
| 结构 | 16 小节:档1(4)+档2(4)+档3(4)+持续(4),~23s | **32 小节** ~46s(档1×8+档2×8+档3×8+持续×8)或保持 16 小节 + 更密 |
| 密度 | 档1 7 层 / 档3 11 层 | 档1 9 层 / 档3 14 层(加节奏吉他/riser/军鼓边击) |
| 层配合 | 各层均匀网格,各唱各的(见 DIAGNOSIS_v6) | **节奏互锁 + 动机对话**(见下) |
| 音区 | 吉他 64-83 与一提 74-79 重叠 | 音区角色化(吉他高、一提中低回声) |

### 母节 v7 三项核心改造

**A. 节奏互锁表**(每层的落点设计在别人空隙里):

| 层 | 落点(拍) | 与谁互锁 |
|---|---|---|
| 贝斯 | 重音 0/1.5/3.0,其余 16 分轻 | 骨架 |
| 鼓 kick | 3+3+2 同贝斯重音 | 齐奏冲击 |
| 吉他 Hook | 重音 0.5/2.0/3.5 | **错开贝斯重音** |
| 铜管刺刀 | 4 音组 0.75/1.25/2.75/3.25 | **填补空隙** |
| 一提音型 | 吉他句尾 16 分回声(延迟 0.25 拍) | **应答吉他** |
| 钢琴 | 每小节 0.0 重击 | 小节锚点 |

**B. 音区角色表**:

| 音色 | 音区 | 角色 |
|---|---|---|
| 贝斯 | 28-50 | 低音主体 |
| 钢琴 | 40-52 | 与贝斯齐奏(厚度) |
| 铜管刺刀 | 57-62 | 中低刺点 |
| 一提音型 | **64-71**(降 8 度) | 中区回声 |
| 二提/中提/大提 | 36-71 | 和声层 |
| 吉他 Hook | 69-83 | **唯一高区旋律** |
| 合唱/pad | 48-62 | 氛围垫 |

**C. 动机对话链**(档3 的 4 小节内):

```
小节1: 吉他 Hook 句头(4 音动机)→ 小节1末: 一提回声(16 分)→ 小节2: 刺刀插入
小节2末: 贝斯高把位应答 → 小节3: 吉他变奏 → 小节4: 齐奏收束(M3)
```

## 3. 子节定义(搜打撤场景映射)

所有子节 = 母节 32 小节内的**层开关 + 密度变形 + 少量过渡元素**。

| 子节 | 游戏场景 | 改动规则(相对母节) |
|---|---|---|
| **S1 搜刮氛围节** | 开局搜刮/舔包 | 鼓→仅 kick 每拍;贝斯→长音+低音脉冲;吉他/铜管/钢琴→关;pad+弦乐+合唱→主导;vel 全域 -20 |
| **S2 探索行进节** | 地图移动/警戒 | 母节档2 全套;吉他→刺点;钢琴→轻击;密度 = 母节 60% |
| **S3 战斗母节** | 交火 | 母节 100% |
| **S4 危机节** | 低血量/被追击 | 母节 + ① 全部旋律层**+1 半音移调**(紧张)② kick 改"心率型"(每拍 2 发,重音错位)③ 刺刀加长(2 音组)④ 加 riser 音色 |
| **S5 撤离冲刺节** | 撤离倒计时 | 母节 + ① 密度 ×1.5(16 分→32 分滚奏)② BPM +8(168→176,整节速度)③ 钢琴/吉他八度叠置 |
| **S6 结算平静节** | 撤离成功 | S1 变体 + 和声停在 Em 长音(4-8 小节)→ 淡出 |

## 4. 转场规范(作曲端 + 游戏端)

**作曲端**(子节代码内置):
1. **小节边界对齐**:切换只发生在 4 小节边界
2. **力度交叉**:进入方在边界前 1-2 拍发低 vel/CC11 先现;退出方边界前 1 拍渐弱
3. **和声预挂**:进入子节的和声在其边界前 2 拍"预挂"(低音先行)
4. **过渡元素**:S2→S3 用 riser(8 拍 16 分上行);S3→S4 用下行 FX;S3→S5 用 32 分滚奏;S3→S6 用 crash + 停

**游戏端**(集成方):
5. **垂直混音**:游戏引擎(FMOD/Wwise)用 `mix_stems.py` 的 5 组 stems 实时控制层音量,支持引擎内渐变
6. **可截断**:任意小节末可快速淡出(50ms),无音乐残留
7. **切换冷却**:同子节重复切换间隔 ≥4 小节,防闪烁
