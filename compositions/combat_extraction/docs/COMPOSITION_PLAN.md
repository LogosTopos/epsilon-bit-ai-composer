# 《搜打撤》战斗背景曲 — 作曲规划 v1(父会话定稿)

> 目标:为超快节奏 PVE 搜打撤枪战游戏写战斗背景曲。
> 本文件是**唯一音乐依据**:所有动机/和声/结构/音区决策已定死。
> 子 Agent 只做:① 忠实翻译成代码;② 工程化(冒烟/自检)。禁止创作新音乐内容。
> 风格:现代军事史诗 + 电子(管弦重奏 + 电子脉冲,参考 COD 战斗曲)。

## 6. 分层模块规格(每层一个文件,独立冒烟)

```
compositions/combat_extraction/
├── docs/COMPOSITION_PLAN.md     (本文件)
├── lib/orch.py                  (Score API,已就位)
├── lib/progs.py                 (角色→(bank,prog,音区,pan,rev) 映射;Agent A 填写)
├── layers/intro_outro.py        (m1-2 Intro + m19-20 Outro)
├── layers/drums.py              (M1 节奏动机全谱:档1/2/3/呼吸)
├── layers/bass_harmony.py       (贝斯 riff + 弦乐和声长音)
├── layers/riff_texture.py       (M2 刺刀 + Hook + 合唱 + 钢琴重击)
├── compose.py                   (总装:注册→按序调用→自检)
└── mix_stems.py                 (后处理:侧链/EQ/响度)
```

**层接口(全部一致)**:
```python
def build(s, bar0, cycle, ch):
    """s: Score; bar0: 起始小节; cycle: 0/1(母 loop 第几次); ch: 通道映射 dict
    返回结束小节号。层内部按 §2 结构表铺自己的声部。"""
```
- 每层**只写自己的角色**(第 5 节表),不碰其他层通道
- cycle=1 时允许**微变**(防腻):鼓 fill 不同、贝斯 riff 变体、Hook 高八度——但和声/结构不变
- 音区纪律:§5 表;任何音超区→修正(不得省略)

## 7. 循环工程规格(硬性)

1. m18 末(第 4 拍)不安排重音/新事件,与 m3 第 1 拍无缝衔接
2. 母 loop 内**无终止式**:全部和弦来自 §4 循环表
3. 呼吸段(m15-16)鼓抽离但和声保持,能量回落不归零
4. 渲染后波形检查:m18→m19(实际是第二圈 m3)边界 RMS 连续(±1dB 内)
