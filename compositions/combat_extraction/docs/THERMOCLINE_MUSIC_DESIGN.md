```
                                    ▲        │波结束(短)

随时垂直叠加:热量过载(heat HUD)、低血量、护盾拦截、换弹、瞬移(事件级,不切节)
```

## 2. 转场设计(状态切换矩阵)

| 切换 | 转场元素 | 说明 |
|---|---|---|
| 波前 → 交火 | **riser**(已有) | 2 小节 16 分上行,进母节 |
| 交火 → 波间 | **down_fx**(已有) | 1 小节下行 + 和声预挂 |
| 波间 → 交火 | **riser** | 同上 |
| 交火 → 时停 | **time_fold 时间折叠**(新元素) | 规格见下(竞品研究校准版) |
| 时停 → 交火 | **time_unfold 时间展开**(新元素) | 32 分 snare 滚奏渐强(2 拍)+ 密度骤回 + 总线低通解除 |
| 交火 → 结算 | **crash_stop**(已有) | 急停 + 休止,进 S6 |
| 热量过载/低血量 | 无转场(垂直) | 游戏端 stems 增益 + 总线效果,音乐状态不动 |

**对齐纪律**(沿用):切换只发生在 4 小节边界;进入方 CC11 ≥70;time_fold/unfold 允许 1 小节边界(时停是玩家主动触发,响应要快,≤1 小节)。

**竞品研究校准(B Agent,2026-08:Doom/Hades/SUPERHOT/Max Payne/CRI 官方)**:
1. **时停音乐不做全局变速**:保留母节 168BPM 不被 warp(节奏识别是母节核心价值);
   进 S-BT 时音乐侧只做 **stems 低通(~800Hz)+ 抽高频打击乐(hat/ghost)+ 心跳保留**;
   **变速只发生在音效侧**(游戏端),并按 CRI 官方建议**预作 S-BT 专用 stems 资产**
   (低通渲染版,游戏内直接切,比实时滤波便宜且可控)
2. **转场只动 stem 权重与滤波,不做速度渐变**(Doom 全素材同调同速模式);
   事件切换排队到 168BPM 小节边界,急停允许立即打断但用 down_fx/crash_stop 兜底
3. **14 层归并为 5 个可听档位**(与 Doom 5 层 / Hades 3-7 变体同构):
   搜刮(S1)→ 常规(母节减层)→ 战斗(母节 14 层)→ S-BT → 结算(S6),
   档内 14 层做平滑渐入(引擎内 stem 权重),不做档间硬切
4. **stinger 系统(新)**:击杀/破甲/换弹完成等事件 → 短促同步化重音
   (1-2 音,timpani 单音或 fx 短脉冲),落 16 分网格,避让枪声频段(Doom 哲学:
   stinger 不盖枪声,是"短能量爆发")
5. **Furi 式硬换曲不采用**(波次制成本高易露馅);相位变化用 5 stems 权重插值模拟

## 3. 温跃层向子节清单(全部遵守禁 stab 红线)

| 子节 | 人格 | 素材(全部母节原位) | 红线符合 |
|---|---|---|---|
| S-准备 | 低威胁警戒循环 | S1 变体:8 分 bass + 长音氛围,无鼓或极轻鼓 | ✅ 无 stab |
| **S-BT(核心)** | **时间冻结** | 心跳 kick(8 分双发 68/80)+ 时间晶体(hook 高区闪烁,每 2 小节 1-2 音)+ 弦乐长音拉长;无 16 分驱动;**竞品校准:音乐不做变速(168 保持),低通感用 stems 渲染时减高频打击乐实现,游戏端配 S-BT 专用低通 stems 资产** | ✅ 无 stab |
| S-呼吸窗 | 波间喘息 | S1 截断 4-8 小节:kick 每拍轻 + bass 8 分 + 长音 | ✅ 无 stab |
| 高波层 | 垂直加层 | fx 低频脉冲 + timpani 加密(引擎内叠加于母节) | ✅ 无 brass 刺刀 |
| 热噪层 | 垂直加层 | fx 高频嘶声 + 低频轰鸣(pad 根音 16 分脉冲) | ✅ 无 brass 刺刀 |
| S4 重做版 | 绝境压迫(弃移调) | 心率 kick + bass 应答原位 + hook 乐句原位(vel +4);**不加 brass** | ✅ 弃多调性/弃 stab |
| S5 重做版 | 冲刺(弃叠置) | 176 BPM + 32 分 hat + 母节 bass/hook 原位;riser 用母节 42-72 版 | ✅ 弃八度叠置/弃 32 分两八度 riser |

**stinger 素材**:击杀/破甲/换弹完成 → timpani 单音(38,vel 72-84,0.3s)或 fx 短脉冲(57,vel 60);落 16 分网格,避让 kick 3+3+2 重音槽(0/1.5/3.0)与枪声频段。

**已验收可直接用**:母节 v9(S3)、S1(搜刮/波间)、S6(结算)、S2(探索/准备备选)。S2/S6 无需改动。

## 4. 创作红线(STATUS 教训 #8 升级版,2026-08)

1. **子节中不再使用 stab 元素**(brass_stab 刺刀一律不用;M3 齐奏只保留 timpani/kick/bass 三件套;riser 用母节 42-72 原版,不加密)
2. **音高一律母节素材原位**(不移调/不叠置/不扩展音区)
3. 子节只做:层开关 + 密度/力度变形 + 人格化乐句重写(节奏型可新写,音高取自母节素材)
4. 可留:hook 乐句(旋律辅助,非刺击)、synth_rhythm(和声节奏)、fx riser(转场/推进工具)
   ——若用户认为 hook/rhythm 也属"stab 家族",可进一步删(待确认)

## 5. 实现顺序(建议)

1. **S-BT 子弹时间子节 + time_fold/unfold 转场元素**(温跃层招牌人格,优先)
2. S-呼吸窗 + S-准备(小改动,波次制必需)
3. 热噪层/高波层(垂直 stems 交付后,游戏端 1 个脚本)
4. S4/S5 按红线重做(可选,交火变化性)
5. S-抢救(远期,主线剧情)

## 6. 与现有交付的关系

- SDC v1(S1→母节×2→S6)= 温跃层"搜-打-撤"最小闭环,可直接作为游戏内"波前→交火→结算"的预混成品
- 波次制改造:SDC v1 的"母节×2"段按波次拆为"母节(波 N)+ 呼吸窗 + 母节(波 N+1)",即音乐侧预混 3 个变体(波 1/波 2/高波),游戏端按波次号切换
- 时停:先上"总线低通+变速"最低可行方案(1 行代码),S-BT 完成后替换
