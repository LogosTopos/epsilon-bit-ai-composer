## 1. 技术勘误(渲染 bug 根因,覆盖 v6 文档错误结论)

**GUGS 精确音色完全响应 CC11**(v6"GUGS 不响应 CC11"结论错误)。
实测 (57,0) 长号:CC11 0 → 静音(-90.3dB),60 → -33.9,72 → -30.7,80 → -28.9,
84 → -28.0,127 → -20.8。旧四档 CC11 60/72 让档1/档2 长号几乎静音 → "音轨存在感扭曲"。
**对策**:CC11 全程 80-84(所有角色都在可闻区),动态差异交给子节的层开关。
