# 《搜打撤 战斗主题》作品说明(v7.1)

> 超快节奏 PVE 搜打撤枪战游戏战斗背景曲。168 BPM,E 小调,Em-C-G-D 循环和声。
> **v7 架构(用户决策):母节 = 游戏高潮段,16 小节全程满配(14 层),起承转合全部留给子节**;
> 内部只做横向乐思(4 轮对话链)。**v7.1 重心(用户决策)**:Bass 是总旋律重心,
> 合成器 = 稀疏点缀辅助层;鼓/贝斯混音加大。全程"宏观规划(父会话)→ 子 Agent 并行执行 → 父会话总装验收"流水线。

---

## 1. 设计规格(功能先于艺术)

| 项 | 设计 | 游戏适配理由 |
|---|---|---|
| BPM 168 | 16 分驱动 | "超快节奏"连发枪感 |
| 母 loop 16 小节(22.9s) | **高潮段满配**:14 层全程在场 | 垂直混音供引擎动态抽层(子节体系) |
| 4 轮对话链 | 每轮 4 小节:句头→一提回声→刺刀插入→贝斯应答→M3 收束→riser 推进 | 横向乐思防腻,无垂直强度渐进 |
| 和声循环 Em-C-G-D | 无终止式 | 天然可循环 |
| 频谱设计 | 低频 25% | 给脚步/枪声定位留窗口 |
| 响度 | 峰值 -1.0 dB(战争级) | 战斗音乐不"礼貌" |

**起承转合不在母节**:层开关/密度增减/力度落差全部留给子节
(子节 = 母节受控改动:Bass 旋律不变音符变少、删音色、加低音等)。

## 2. 动机与重心(v7.1)

- **M1 节奏动机**:kick 3+3+2(0.0/1.5/3.0 拍)+ snare 2/4 + hat 16 分 + 幽灵音(反拍)
- **M2 威胁动机**:铜管半音刺刀(A3-Bb3 组,两轮和谐修正后 57/58/62)
- **M3 冲击动机**:每轮第 4 小节第 3 拍齐击(brass 57 + timpani 38 + kick + bass)
- **Bass = 总旋律重心**(用户决策):16 分驱动 + 4 轮旋律模式渐进
  (轮1 基础脉冲 → 轮2 高把位弧线冲 52 → 轮3 旋律跳跃 → 轮4 收束回环)
  + 每轮 bar2 末高把位应答(对话链);vel 102/重音 112,全场最响
- **合成器/小号 = 稀疏辅助**(用户决策):每小节 1-3 音点缀(0.5/2.0/2.5/3.5 槽),
  高区五声色彩,力度 66-72(不抢 bass)
- **一提回声**:bar1/3 句尾(3.5/3.75,64-71 带,应答 bass 乐句)

## 3. 音色(两版对比,v7 音色删减)

| 角色 | 选择 | 说明 |
|---|---|---|
| drums | GUGS Power Kit(128/16) | kick/snare/crash 三库最强 |
| bass | GUGS Finger Bass(0/33) | E1 最响,主角 |
| **hook** | **trumpet (56,0)** / **synth (0,80)** | **两版**:小号实测 -23.7dB(军事史诗本命)/ 方波 +6 vel 补偿 |
| brass_stab | GUGS (57,0) Trombone | M2 刺刀 + M3 |
| timpani | (0,47) | 2.0 根音重击 + M3 齐击 |
| 弦乐/合唱/pad/钢琴 | MuseScore/GUGS | 和声层与锚点 |
| fx | (0,80) | 轮末五声 riser + 每小节低脉冲 |
| synth_rhythm | (0,80) | 切分和声节奏层(原"节奏吉他"位) |

**v7 关键删减**:`guitar_dist(0,30)` 已删除——用户发现库乐队 GM 映射
program 30 = Hard Rock.patch(经 GM_Instrument_Mapping.plist 验证),是全曲唯一跨流派音色。

**技术勘误(v7,覆盖 v6 错误结论)**:GUGS 精确音色(57,0)等**完全响应 CC11**;
低 CC11(60/72)会让长号几乎静音(实测 0 → -90dB,72 → -30.7,84 → -28.0)。
对策:CC11 全程 80-84 微弧线(轮起点 80/82/84/82),无档位级落差。

## 4. 渲染与混音

```bash
# 双库渲染(顺序不可反)
fluidsynth -F stems/full.wav -r 44100 -R 0.9 -C 0 -g 1.2 \
  ../../soundfonts/MuseScore_General.sf2 ../../soundfonts/Rock_GeneralUser_GS_v1.471.sf2 in.mid
# 混音(侧链)—— 运行前清缓存
rm -rf __pycache__ lib/__pycache__ layers/__pycache__ && rm -f stems/stem_*
python3 mix_stems.py --mid in.mid --render-stems
```

混音链:鼓瞬态压缩(**volume 1.28,鼓要大**)→ 贝斯 sidechain(**1.55,重心**)
→ 弦乐低切(0.75)→ stab 压缩(**1.15**,旋律可闻)→ 氛围弱化(0.7)→ 总线 glue + limiter。
实测 stem 占比(混音后):drums ≈ -18.6dB / bass ≈ -18.5dB(主导)、stab ≈ -28dB(旋律可闻)、
strings/atmosphere -35/-36dB(垫底)——有用音色无失聪。
压码:峰值补 -1dB + alimiter 0.95 + libmp3lame -q:a 2 + ID3。
**构建入口:`./build.sh`**(清缓存 → 双版生成 → 双版审计 → 渲染混音)。
**主成品 = 合成器版**(用户听感:合成器 > 小号),trumpet 版保留对比。

## 5. 验证(数值代理协议,v7 全过)

- **自检 0 告警 0 冲突**(两版)
- **密度:全 16 小节 × 2 圈 = 14 层**(audit_v7.py)
- **互锁:非打击乐重音层同 16 分槽 ≤2,0 违规**(bass 重音 0/1.5/3.0、hook 0.5/2.0/3.5、brass 0.75/1.25/2.75/3.25 互错)
- **碰撞:60 次 ≤150**(剩 M2 语义性张力,短音弱力度)
- **弧线平稳(高潮段口径)**:轮1 -21.7 → 轮2 -20.3 → 轮3/4 -20.1 dB,无档位落差;回环连续
- 时长 55.2s(母 loop 22.9s 可无限循环);MP3 峰值 -1.0 dB
