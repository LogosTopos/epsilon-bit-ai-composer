# 《搜打撤 战斗主题》作品说明

> 超快节奏 PVE 搜打撤枪战游戏战斗背景曲。168 BPM,E 小调,Em-C-G-D 循环和声。
> 全程"宏观规划(父会话)→ 子 Agent 并行执行(音色/鼓/贝斯和声/riff 纹理 4 层)→ 父会话总装验收"流水线。

---

## 1. 设计规格(功能先于艺术)

| 项 | 设计 | 游戏适配理由 |
|---|---|---|
| BPM 168 | 16 分驱动 | "超快节奏"连发枪感 |
| 母 loop 16 小节(22.9s) | 3 强度档 + 呼吸 | 可无限循环;垂直分层供引擎动态混音 |
| 档1(m3-6) | 鼓 3+3+2 + 贝斯 riff | 骨架 |
| 档2(m7-10) | +弦乐和声 + 铜管半音刺刀(M2) | 强度 +1 |
| 档3(m11-14) | +Hook 吉他 riff + 合唱 + 钢琴重击 + 16 分驱动 | 全奏 |
| 呼吸(m15-16) | 鼓抽离、和声保持 | 防疲劳 + 回环 |
| 和声循环 Em-C-G-D | 无终止式 | 天然可循环 |
| 频谱设计 | 档3 低频 25% | 给脚步/枪声定位留窗口 |
| 响度 | 峰值 -0.6 dB(战争级) | 战斗音乐不"礼貌" |

## 2. 动机库

- **M1 节奏动机**:kick 3+3+2(0.0/1.5/3.0 拍)+ snare 2/4 + hat 8→16 分
- **M2 威胁动机**:铜管半音刺刀(E4-F4-E4-F4 | E4-F4-G4-F4)
- **M3 冲击动机**:每圈第 4 小节第 4 拍齐击
- **Hook**:E 小调五声 riff(Em: E5-G5-A5-B5-A5-G5-E5-G5 …),cycle 2 微变

## 3. 音色(子 Agent A 三库实测对决)

| 角色 | 选择 | 实测依据 |
|---|---|---|
| drums | **GUGS Power Kit(128/16)** | kick -22.5/snare -22.3/crash -23.9,三库最强;M1 pattern -19.1dB |
| bass | GUGS Finger Bass(0/33) | E1 -16.6dB 最响,E1→E2 一致 |
| guitar | GUGS Distortion(0/30) | -18.0dB 最响最冲 |
| brass_stab | MuseScore Expr 17/56 | CC11=110 时 -16.3dB,比 GM 响 9dB |
| 弦乐/合唱/定音鼓 | MuseScore(沿用) | Expr 动态可 CC11 分档 |

**关键工程结论(Agent A 实测)**:
- GUGS **不响应 CC11**(力度驱动)→ 动态分档由层代码 vel 承担(72-104)
- 双库叠加渲染:FluidSynth 后加载库优先,**MuseScore 在前、GUGS 在后**,Expr bank 保留共存
- SGM-V2.01 全角色败北(247MB,建议删除)

## 4. 渲染与混音

```bash
# 双库渲染(顺序不可反)
fluidsynth -F stems/full.wav -r 44100 -R 0.9 -C 0 -g 1.2 \
  ../../soundfonts/MuseScore_General.sf2 ../../soundfonts/Rock_GeneralUser_GS_v1.471.sf2 \
  Combat_Extraction.mid
# 混音(侧链)
python3 mix_stems.py --render-stems
```

混音链:鼓瞬态压缩 → 贝斯 **sidechain(鼓点让位,冲击感)** → 弦乐低切 → stab 压缩 → 氛围弱化 → 总线 glue + limiter。

## 5. 验证(数值代理协议)

- **自检 0 告警 0 冲突**(修掉:总装串行 bug(101 小节)、缺 tempo 事件、引子 crash 重叠)
- **强度弧线**(混音版分段 RMS):

```
Intro -28.5 → 档1 -28.0 → 档2 -23.9 → 档3 -21.0(峰)→ 呼吸 -31.4 → Outro -35.4
```

- **循环稳定**:loop1 vs loop2 各档差 ≤0.3dB;循环边界为设计内"回落再起"
- **频谱**:档3 低频 25%,1k-4k 37%(hook 舞台),音效窗口保留
- **密度**:档1 22 → 档3 84 音符/小节(×4),呼吸 20,Outro 2
- 时长 55.2s(母 loop 22.9s 可无限循环);MP3 峰值 -0.6 dB

## 7. 交付形态(游戏集成)

- 母 loop = m3-18(16 小节),游戏端按强度档垂直混音(每档 4 小节独立可循环)
- 如需 FMOD/Wwise 分层:用 `mix_stems.py` 的 5 组 stems 直接导入
- Outro(m35-36)可截断;任意时刻可淡出(引擎 ducking 由音频端负责)
