# 《深渊对位 / Contrapunctus Abyssi》作品说明

> 单乐章,5:35。相对《深渊四章》组曲的**密度实验**:短时间高密度技法 + 链路层补课。
> **v2 重写(依据用户反馈"更流畅、自然、和谐"与编曲问题回顾)**:
> 从"技法展览"改为"音乐叙事"——和声声部连接、帕萨卡利亚三组连续演化、
> 对比主题、角色化配器、速度渐变、8 小节高潮。

## 1. 形式与技法清单(5:35)

| 段落 | 小节 | 速度 | 内容 | 技法 |
|---|---|---|---|---|
| 引子 | 1-8 | 54→72 | 钟声 + 持续音 + X 碎片 + 主题预示 | 动机呈示,roll 轻滚奏 |
| 帕萨卡利亚 A 组 | 9-20 | 72 | 弦乐室内:一提主题 → 双簧管对位 → 长笛高八度主题 | **固定低音 + 和声声部连接**(每 2 拍一和弦,i/V7/viio6-5/VI/bII,共同音保持/就近解决) |
| B 组 | 21-32 | 72 | 转调演化:F 长笛主题 → Gm 中提主题 → Eb 一提主题 | 主题传递链 + 震音 + 竖琴加密,织体渐变 |
| C 组 | 33-44 | 72 | A7 弱音小号 → Dm 全奏初现 → 铜管全奏推进 | 定音鼓滚奏渐强 + 镲/大鼓 + 低音八度叠置 |
| 间插段 | 45-48 | 72→84 | 双簧管**对比主题 T2** 独奏 | 新材料(五度大跳 + 附点抒情)+ 属准备 |
| 赋格 | 49-80 | 84→96 | 四声部呈示(大提→中提→二提→一提)+ 对题 CS2(延留/回转) | **呈示期纯对位无和声**(巴赫式);间插段模进对话;小号/大管八度进入;X 碎片序列 |
| 密接和应 | 81-84 | 96→104 | 主题错 2 小节三层叠加 | stretto + 属持续 |
| 高潮 | 85-92 | 104 | 8 小节:增时低音 + 倒影头 + 十六分下行 → 全奏保持 | **4 级渐强阶梯**(66→74→80→84)+ 合唱进入 + 定音鼓/镲/大鼓 + 钟琴微光 |
| 尾声 | 93-108 | 104→72 | D 大调圣咏(四部和声连接)+ 皮卡迪 | **渐弱**(60→54→48→42→40)+ 钟声余韵 + 竖琴琶音 |

**调性旅程**:d → F(关系)→ g → Eb(bIII)→ A7(属)→ d → **D 大调(皮卡迪)**
**主题传递链**:大提/一提 → 双簧管 → 长笛 → 中提 → 弱音小号 → 一提 → 长笛 → 小号/大管 → 圆号 → 三层密接 → 圣咏

## 2. v2 编曲问题回顾与修复(数据驱动)

| v1 病症(实测数据) | v2 修复 |
|---|---|
| 配器碎片化:11/20 乐器活动 ≤16%,弱音小号/钟琴/单簧管各 4%/4%/3%(出场一次即弃) | 角色化:长笛=高音持续、双簧管=中音独奏、圆号=和声支撑、巴松=低音八度、定音鼓=组C起持续;木管每组都在场 |
| 和声僵死:低音每拍动,和声每 4 拍 1 个静态三和弦 | 和声**声部连接器**(connect):每 2 拍 1 个功能性和弦,相邻和弦移动最小化,转位/经过和弦常态化 |
| 密度倒挂:帕萨卡利亚 6-8 声部 > 赋格 2-3 声部,锯齿状 4 小节一跳 | 赋格呈示期纯四声部对位(巴赫式),间插/进入期才加内声部;帕萨卡利亚三组密度渐进 |
| 主题贫乏:全曲只有 T1+CS 两个材料 | 新增对比主题 T2(五度大跳+附点)与性格化对题 CS2(延留/回转) |
| 节奏机械化:起始集中在拍头拍尾,全均匀四分 | T1/CS2/T2 全部附点化,1.5/0.5 组合,呼吸感 |
| 高潮 4 小节被截断 + 速度硬切 | 高潮 8 小节 4 级渐强;54→72→84→96→104→72 全渐变(tempo_ramp) |

## 3. 链路层(v2 保留,承自 v1 补课)

| 层 | 实现 |
|---|---|
| 声像 | CC10 管弦乐摆位,随音色切换发出 |
| 深度 | CC91 分层混响发送(竖琴/钟近场亮,打击乐干) |
