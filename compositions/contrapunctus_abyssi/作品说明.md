# 《深渊对位 / Contrapunctus Abyssi》作品说明

> 单乐章,4:36。相对《深渊四章》组曲的**密度实验**:时长缩短到 1/3,作曲技法密度与
> 音轨复杂度提升,并补上"曲谱 → MP3"链路中缺失的层(声像/混响发送/连续动态/人性化)。

## 6. stem 分轨混音实验(4.1 落地)

**目标**:补齐 HANDOVER 3.2 指出的混音层缺口(无 stem 分轨 → 无独立 EQ/压缩)。

**做法**:`render_stems.py` 把 MIDI 按通道组拆成 5 个 stem(格式 1,保留 meta 轨与全部
CC10/CC91/CC11 事件),各自按标准管线渲染;`mix_stems.py` 用 ffmpeg 混音。

| stem | 通道 | 处理链 |
|---|---|---|
| strings | 2-6(一提/二提/中提/大提/低音) | HP 30Hz + 轻压缩(thr -28dB, r1.8) |
| woodwinds | 7,8,10(长笛/双簧管/单簧管/大管) | HP 45Hz + 1.6× |
| brass | 12,13(圆号/小号/弱音小号/长号/大号) | HP 35Hz + 1.15× |
| percussion | 9,11(鼓/定音鼓) | 瞬态压缩(thr -18dB, r2.5, a5ms) |
| color | 0,1,14,15(钟/竖琴/合唱/管风琴/钢片琴/钟琴) | HP 28Hz + 1.5× |

**保真度验证(基线混音 = 纯相加 vs 整轨渲染)**:全局 RMS -29.3 vs -29.7 dB,
峰值 -4.9 vs -5.3 dB,各分段差 ≤0.4 dB → stem 拆分无损。

**分段 RMS 对比(生产混音 vs 整轨渲染)**:

```
引子 -42.9→-39.6(+3.3)  帕萨卡利亚 -28.9→-28.1(+0.8)  赋格 -32.6→-31.4(+1.2)
高潮 -24.6→-23.9(+0.7)  尾声 -28.4→-27.7(+0.7)  末和弦 -31.5→-30.6(+0.9)
```

**效果与取舍**:
- 色彩组提升(1.5×)让引子的钟/竖琴/管风琴更清晰(引子 +3.3 dB);
- 打击乐瞬态压缩收住镲/定音鼓尖峰(WAV 峰值 -5.3 → -7.4 dB,MP3 压码余量更大);
- 木管提升后赋格间插段(长笛/单簧管对话)与 St5 长笛旋律更突出;
- 代价:整曲响度略升(全局 RMS +0.8 dB),动态结构保持不变。

**成品**:`Contrapunctus_Abyssi_stem_mix.mp3`(峰值 -0.7 dB,与原版同口径,ID3 同款)。
**待用户试听裁决**:两版(整轨 vs stem)哪段更顺耳,再决定是否回写正式成品。
**复用**:新作品只需在 `render_stems.py` 的 GROUPS 里改通道映射即可套用。
