# 《深渊之战 / Battle in the Abyss》作品说明

原创战斗风格 MIDI 作品。本曲的核心实验:**BPM 可变(变速叙事)**——不再是匀速行进。

## 交付文件

| 文件 | 说明 |
|---|---|
| `Battle_in_the_Abyss.mid` | 标准 MIDI(格式 1,11 轨,480 TPB,4/4) |
| `Battle_in_the_Abyss_v2.wav` | 无损渲染(FluidSynth + MuseScore_General) |
| `Battle_in_the_Abyss_v2.mp3` | 试听版(limiter 防削波,峰值 -0.5 dB 内) |
| `compose.py` | 生成脚本(`--speed/--transpose/--out` 参数) |

## 变速设计(Tempo Map)

| 段落 | 小节 | BPM | 乐理意图 |
|---|---|---|---|
| 引子 | 1-8 | 96 | 黑暗铺垫,定音鼓滚奏渐强(张力蓄积) |
| A 段(主题) | 9-32 | **132** | 段落切换提速,能量跃升(爆发) |
| B 段(推进) | 33-44 | **144** | 加速推进,十六分镲 + 四平底鼓 |
| 过渡 | 45-46 | **132→120** | ritardando 减速(喘息),军鼓滚奏 |
| C 段(高潮) | 47-62 | **138** | 再次爆发,全奏(铜管/合唱/失真吉他) |
| 尾声(冲刺) | 63-66 | **142→148 逐小节加速** | 冲刺,密度拉满 |
| 重击 | 67-68 | 150 → 骤停 | 最终重击 + 静默 |

## 战斗乐理语言

- **调性与和声**:A 小调;驱动进行 i-VI-III-VII(Am-F-C-G)循环,A 段推进;iv(Dm)用于 B 段离调色彩;高潮回归 F-G-Am 强力收束
- **节奏层**:闭镲八分脉冲(A 段)→ 十六分(B/C 段);底鼓切分(2.5/3.5 拍)→ 四平推进(B)→ 八分 drive(C);军鼓 backbeat(2/4 拍)+ 滚奏渐强过渡
- **低音**:八分音符根音脉冲 + 小节末拍五音导向(级进引导下一和弦)
- **旋律**:切分动机(附点+短音)、十六分冲刺音列、模进推进、重复音驱动(B 段);C 段高八度再现 + 尾声逐小节加速下的音列冲刺
- **织体**:弦乐 staccato 击奏(off-beat 重音)、铜管小节头重音、失真吉他强力和弦、合唱长音、定音鼓滚奏/重击

## 验证结果

- **Tempo map 校验**:MIDI 读回 BPM 序列 [96,132,144,132,120,138,142,144,146,148,150] 与设计完全一致
- **声部核对**:主旋律切分动机、低音八分 riff 符合设计
- **动态曲线**(渲染后分段 RMS):引子 -36.5 dB → A 段 -24.4 → B 段 -23.2 → 过渡 -22.8 → **C 段高潮 -19.7 dB(峰值)** → 冲刺 -23.2 → 重击骤停
- **防削波**:渲染 gain 0.8 保证 WAV 零触顶;MP3 端 alimiter 限制峰值,无硬削波

## 与以往作品的区别

| | 以往(《无名之渊》等) | 本曲 |
|---|---|---|
| 速度 | 固定 66-69 BPM,匀速 | **96→150 BPM 变速叙事** |
| 拍号 | 3/4 摇曳 | 4/4 战斗脉冲 |
| 节奏密度 | 八分音符为主 | 八分→十六分递增,冲刺段十六分拉满 |
| 鼓组 | 无 | 完整打击乐层(底鼓/军鼓/镲片/滚奏) |
| 能量结构 | 缓慢渐强 | 段落切换提速 + 减速喘息 + 冲刺骤停 |

> 音乐为原创,不含任何原曲旋律。
