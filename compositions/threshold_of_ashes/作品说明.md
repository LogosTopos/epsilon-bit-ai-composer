# 《灰烬阈限》Threshold of Ashes

这是一个自主创作的三曲作品集，重点不是把每首曲子都做成同一个“满配高潮循环”，而是把段落之间的变化写进音乐本身。

## 曲目

| 文件 | 性格 | 主要转场设计 |
|---|---|---|
| `Ashen_Approach` | 低速探测 → 裂隙全奏 → 余波回收 | 和声预挂、两小节五声渐升、急停后回到低速 |
| `Riftline_Hunt` | 远距锁定 → 交火 → 断层追击 → 逃逸 | 先改变节奏密度，再改变速度；滚奏转入高潮 |
| `Dawn_Extraction` | 夜航 → 破晓前线 → 日光突破 → 安全窗 | 通过 C 和弦过桥到 F 大调，不在段落边界裸切调性 |

## 转场原则

1. 新段落的节奏先以低力度出现。
2. 旧段落在边界前抽掉部分密度，给新段落留空间。
3. 新段落根音/五度提前半小节至一小节预挂。
4. 渐升音色先进入，完整主旋律后进入。
5. 速度变化放进两小节转场，不在裸露的强拍上直接跳变。
6. 急停不是把所有音符同时砍掉，而是保留两拍和声余像，再进入下一节。

## 复现

```bash
cd /Users/topologyw/Projects/ε-bit-ai-composer/compositions/threshold_of_ashes
./build.sh
```

默认使用 `/opt/anaconda3/bin/python`（Conda base），并使用项目的
`soundfonts/MuseScore_General.sf2` 渲染。每首作品都会生成 `.mid`、`.wav`、`.mp3`，
并由 `verify.py` 检查音符数量、时长、峰值和 `END` 标记。
