# 《深渊四章 / Quattuor Abyssi》作品说明

> 四乐章管弦乐组曲,总长 **15:01**。本项目是 ε-bit-ai-composer 从"单曲小品"到
> **完整曲目创作**的探索:**~28 音轨全编制管弦乐、循环动机体系、赋格/卡农/应答对话/
> 双主题对位、系统性多旋律变奏**。
>
> 流水线:LLM 设计结构(总谱设计.md)→ 确定性 Python 生成 MIDI(lib/ + 四乐章脚本)
> → FluidSynth + MuseScore_General.sf2 渲染 → 峰值管理压 MP3。全流程本地,原创旋律。

## 2. 循环动机体系(全曲统一)

**动机 X(深渊动机)**:D–C#–A(下行小二度 + 下行大三度,♩. ♪ ♪)。

| 形态 | 出现 |
|---|---|
| 原形 X | 乐章 I 主题 A 头、赋格段主题、紧接段卡农;乐章 II 尾声"深渊窥视";乐章 IV 赋格主题 |
| 倒影 X-inv(A–B–D 上行) | 乐章 II 主题 C("从深渊上升的光") |
| 增时 X-aug(Bb–A–F 二分音符) | 乐章 III 主题 D("深渊的呼吸");乐章 IV 合唱增时主题 |
| 扩大化 X(四分音符) | 乐章 IV 赋格主题头 |
| 双主题对位 | 乐章 IV 全奏:主题 A(快速层,弦乐/木管)+ 主题 D 增时(慢速层,合唱)= 纵向叠置 |

## 4. 各乐章设计要点

### 乐章 I《坠落》
- **引子**(66):D 持续音 + 教堂钟 + 定音鼓滚奏渐强 + 动机 X 碎片(大提琴)
- **呈示**(84):主题 A 由一提演奏(头=动机 X,和声从属七 A7 出发,不落俗套);
  木管应答对话(Bb-Gm-C7-F 的 X 移调);主题 B 双簧管独奏(F 大调)
- **发展**(84→108):**赋格段**——主题 X 五次进入(一提→二提五度答题→大提→长笛→长号),
  八分对题流动线;紧接段 X 卡农随和声移调(D/Bb/Bb/A);A7 属持续渐强
- **再现**(84):全奏(长笛叠旋律/铜管柱式/合唱/竖琴/定音鼓);主题 B 再现于 D 大调(光明色)
- **尾声**(66):归于寂静,钟声 + X 回声

### 乐章 II《流光》
- 主题 C 倒影头 + 拨弦弦乐 + 竖琴/钢片琴微光 + 三角铁
- B 段:**三声部卡农**(长笛/双簧管/单簧管错两小节,d 小调阴影)→ 震音小高潮
- A' 段:中提琴**下方六度对位**(非和弦音就近归位,承袭既有规则)
- C 段:**hocket 对置**(木管 ↔ 拨弦互答 5-6-1 细胞)
- D 段:三声中部,单簧管独奏 + 双簧管应答
- A'' 段:短笛高八度再现(全曲最亮);尾声"深渊窥视"后 F 大调拨弦收束

### 乐章 III《沉眠》
- 主题 D:弦乐四部合唱,头 = X 增时(Bb-A-F)
- 反复:合唱叠置 + 圆号对位装饰 + 竖琴
- 变奏 1:**减缩**——长笛十六分音型 + 双簧管乐句尾回声 + 钢琴分解
- 变奏 2:**卡农**——大提琴/中提琴错两小节,g 小调暗色 + 英国管回声
- 变奏 3:**圣咏**——铜管柱式 + 弦乐八度 + 合唱 + 管风琴 + 定音鼓滚奏(全曲峰值区)
- 尾声:长笛 + 钢片琴,降 B 持续音渐弱至 -52 dB

### 乐章 IV《觉醒》
- **赋格**(96):主题 E = X 扩大化 + 级进延续;六次进入
  (大提 d → 中提 a → 二提 d → 一提 a → 长笛+大管 d → 小号 d+圆号 a)+ 四段对题 + 紧接段
- 间奏(100):Bb-Gm-Eb-A7 序列,木管 X 应答,震音渐强,属驻留
- **双主题全奏**(132):主题 A 快速层(弦乐/长笛)+ 主题 D 增时慢速层(合唱,头=X 增时)
  纵向叠置;打击乐/定音鼓;属七滚奏
- **皮卡迪尾声**(88):D 大调终曲圣咏(合唱+管风琴+钟声+竖琴),末和弦全奏收束

## 5. 验证结果

- **MIDI 结构**:组曲 68 轨,格式 1,480 TPB;tempo map 读回
  [66,84,96,108,84,66 | 300 | 76 | 96,100,132,88];拍号 {4/4, 6/8} ✓
- **生成时自检**:各乐章音色切换冲突 0、同刻同音重叠 0、音区越界 0
- **渲染后动态曲线**(分段 RMS,本文档口径):

```
乐章 I:  引子 -35 → 呈示 -35 → 发展 -32 → 属持续 -27 → 再现 -25(峰)→ 尾声 -45
乐章 II: A -31 → B 卡农 -29 → D 三声中部 -34(谷)→ A'' -29 → 尾声 -38
乐章 III:主题 -35 → 反复 -31 → 变奏2 -34 → 变奏3 -26(峰)→ 尾声 -52
乐章 IV: 赋格 -31(进入点逐级 -32.5→-27)→ 间奏 -29 → 全奏 -23(峰)→ 尾声 -27
组曲:    I -28.9 / II -34.4 / III -31.6 / IV -28.4(2s 间隙)
```

- **防削波**:渲染 gain 1.2,WAV 峰值 -3.4/-2.4 dB 零触顶;MP3 端 volumedetect →
  boost 至 -1.2 dB + alimiter 保护
