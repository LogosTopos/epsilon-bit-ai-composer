# 《深渊四章 / Quattuor Abyssi》总谱设计

> 管弦乐组曲,四个乐章,约 15 分钟。本项目的核心实验:**从"单曲战斗小品"升级为
> "完整曲目"** —— 循环动机体系、四乐章形式、全编制管弦乐配器、对位织体与多主题变奏。
>
> 设计原则:LLM 完成音乐结构设计(本文档),确定性 Python 生成 MIDI(各乐章脚本),
> FluidSynth + MuseScore_General.sf2 渲染。本曲为原创,不含任何既有作品旋律。

---

## 1. 循环动机体系(贯穿全曲的统一材料)

| 动机 | 形态 | 音高结构 | 节奏 | 出现 |
|---|---|---|---|---|
| **X** 深渊动机 | 下行小二度 + 下行纯四度 | D–C#–A(D 小调) | ♩. ♪ ♪ | 四乐章核心细胞 |
| **X-inv** 倒影 | 上行小二度 + 上行纯四度 | A–B–D(F 大调) | ♩. ♪ ♪ | 第二乐章(流光)主题头 |
| **X-aug** 增时 | X 的节奏扩大 | Bb–A–F(降 B 大调) | 二分音符 | 第三乐章(沉眠)主题头 |
| **X-frag** 碎片 | X 的任意两音/移调 | 各种移调 | 各种 | 发展部/间奏的应答对话 |

循环关系:
- 第二乐章主题 C 是 X 的**倒影**("从深渊上升的光")
- 第三乐章主题 D 是 X 的**增时**("深渊的呼吸")
- 第四乐章赋格主题是 X 的**扩大化骨架**(X 头 + 级进延续)
- 第四乐章尾声把第一乐章主题 A(快速)与第三乐章主题 D(慢速)纵向叠置 = **双主题对位**

| 乐章 | 标题 | 调性 | 拍号 | 速度 | 形式 | 实际时长 |

| II | 《流光 / Coruscation》 | F 大调 | 6/8 | 八分=200ms | 谐谑回旋:AB A' C D(三声中部)A'' + 尾声 | 2:19 |

## 3. 第一乐章《坠落 / Descent》(d 小调,4/4)

**和声语言**:lamento 进行 **i–VI–iv–V7**(Dm–Bb–Gm–A7),全乐章循环骨架。
属七 A7(含 C# 导音)是动机 X 半音的来源。

### 3.1 结构

| 段 | 小节 | 速度 | 内容 | 配器 |
|---|---|---|---|---|
| 引子 | 1-8 | Lento 66 | D 持续音 + 钟声 + 定音鼓滚奏渐强;动机 X 碎片(大提琴)+ 竖琴琶音;m7 弦乐预示 X | 低音提琴/管风琴/钟(教堂钟)/定音鼓/竖琴/大提琴 |
| 呈示·主题A | 9-24 | Andante 84 | 主题 A(16 小节,弦乐);大提琴拨弦 ostinato;中提琴对位线;竖琴琶音;m23-24 A7 半终止 | 一提/二提(八度)/中提/大提/低音提琴/竖琴 |
| 呈示·连接 | 25-28 | 〃 | 木管应答对话(X 碎片:长笛↔单簧管、双簧管↔大管),弦乐震音 pp | 木管组/弦乐 |
| 呈示·主题B | 29-40 | 〃 | 主题 B(F 大调,双簧管独奏 + 长笛应答);弦乐拨弦伴奏;圆号持续音;m39-40 C7 过渡 | 双簧管/长笛/弦乐/圆号/竖琴 |
| 发展 | 41-64 | 84→108 | **赋格段**:动机 X 的四次进入(VlnI→VlnII 五度答题→Celli→木管),对题级进线;m53-56 铜管序列(Bb-Gm-A7);m57-60 紧接段(stretto 卡农);m61-64 属持续音 + 渐强 | 弦乐/木管/铜管/定音鼓 |
| 再现 | 65-92 | 84 | 主题 A 全奏(长笛八度叠旋律、铜管柱式和弦、合唱长音、定音鼓);主题 B 再现于 **D 大调**(光明色);m89-92 Bb→A7→Dm 收束 | 全编制 |
| 尾声 | 93-98 | Lento 66 | D 持续音回归,钟声 D4,动机 X 碎片渐弱,单记定音鼓 | 低音/钟/大提琴 |

### 3.2 主题 A(16 小节,弦乐齐奏)

```
动机 X 头:  D5 ♩.  C#5 ♪  A4 ♪        (m9)
持续:       B4 ♩ A4 ♩ D5 ♩. E5 ♪      (上行到 E5,级进)
变奏:       F5 ♩ E5 ♪ D5 ♪ C#5 ♩. A4 ♪ (m11,内嵌 X)
回折:       B4 ♩ C5 ♩ A4 ♩. G4 ♪       (m13,下降)
推进:       A4 ♩ B4 ♪ C5 ♪ D5 𝅗𝅥        (m14-15,模进)
半终止:     F5 ♩ E5 ♩ D5 ♪ C#5 ♪ A4 ♩  B4 ♩  (m15-16,停在属音)
```
后 8 小节(对应段)同一旋律,收束处改为 A7→Dm 完成终止。旋律全程在 d 自然小调内,
C# 只在 A7 处出现(半音色彩唯一来源,与和声同步)。

### 3.3 主题 B(12 小节,F 大调,双簧管)

```
m29:  F5 ♩ A5 ♩ G5 ♩ F5 ♩     (倒影头 X-inv: F–G–A 上行)
m30:  E5 ♩. D5 ♪ C5 ♩ D5 ♩    (下行叹息)
m31:  C5 ♩. Bb4 ♪ A4 ♩ C5 ♩   (内声部涟漪)
m32:  D5 𝅗𝅥 C5 𝅗𝅥              (半音收束感)
m33-36: 上行模进(F5 A5 → G5 Bb5),m37-40 渐落至 C5 终止
```

## 6. 第四乐章《觉醒 / Awakening》(d 小调 → D 大调,4/4)

### 6.1 赋格(Moderato 96,m1-28)—— 多音轨交互的核心展示

**主题 E(赋格主题,4 小节)**:动机 X 扩大化 + 级进延续

```
m1:  D4 ♩ C#4 ♩ A3 ♩ A3 ♩     (X 头,扩大)
m2:  B3 ♩ C4 ♩ D4 ♩ E4 ♩      (级进上升)
m3:  F4 ♩ E4 ♪ D4 ♪ C#4 ♩ D4 𝅗𝅥   (回落,内嵌 X)
```

**答题**:五度答题(A 小调:A3 G#3 E3…)。**对题**:八分音符级进流动线。

| 进入 | 小节 | 声部 | 调性 |
|---|---|---|---|
| 1 | m1 | 大提琴 | d 小调(主题) |
| 2 | m5 | 中提琴 | a 小调(答题) |
| 3 | m9 | 二提 | d 小调 |
| 4 | m13 | 一提 | a 小调 |
| 5 | m17 | 长笛 + 大管(八度) | d 小调 |
| 6 | m21 | 小号(主题,d)+ 圆号(答题,a) | 双铜管进入 |
| 紧接段 | m25-28 | 一提/二提/中提琴 X 卡农(错一小节)+ 滚奏 | d 小调 |

### 6.2 间奏(m29-40):和声序列 Bb–Gm–Eb–A7,木管应答对话,弦乐震音,渐强。

### 6.3 双主题全奏(Allegro 132,m41-64)—— 循环再现的高潮

- **主题 A**(第一乐章)快速层:弦乐 + 木管八度叠置 + 铜管柱式和弦
- **主题 D**(第三乐章)慢速层:合唱 + 管风琴,增时二倍,与主题 A **纵向叠置**
- 定音鼓 + 大鼓 + 镲,全奏;m57-64 序列上行(Dm–Bb–Gm–A7),属七驻留,滚奏

### 6.4 皮卡迪尾声(Maestoso 88,m65-84)

D 大调!管风琴 + 合唱终曲圣咏(D–Bm–G–A | D…),钟声 D 大调三音列,竖琴琶音,
末和弦 D 大三和弦全奏 + 定音鼓滚奏,渐弱收束。

## 8. 转场技术(承袭"转场五件套")

1. 节奏先现:新段律动在段末 1-2 小节弱力度先现
2. 密度渐进:鼓/织体逐步抽离或恢复
3. 音色提前切换:program change 落在无声区(滚奏/休止中)
4. 和声预挂:滚奏/留白后段先落新低音,爆发落在已准备的和声上
5. 速度中间值:乐章间用长休止 + 新速度直接建立(乐章边界),乐章内变速走中间值

乐章衔接:每乐章结尾 2 秒休止 + 新速度/拍号/调性直接切换(组曲惯例)。

## 9. 验证方案

1. **生成时**:每乐章声部核对(各轨音符数/音色)、音区越界告警、同轨同时刻同音高冲突检查、
   音色切换冲突检查(program change 时旧音色必须已静音)、转调/动机落点核对
2. **渲染后**:分段 RMS 曲线(引子低 → 高潮峰 → 尾声静,乐章内部与全曲两级)、峰值 ≈ -1.0 dB
3. **结构核对**:MIDI 读回 tempo map / 拍号序列与设计一致
