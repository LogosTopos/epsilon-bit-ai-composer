# 母节 v6 问题诊断 — 为什么"每个音色单拎能听,合在一起各唱各的戏"

> 用户反馈(原始):"各种伴音色出现的位置不太对,音轨数不够,层次感不足,
> 已有的不同音色层的配合不够好,有种每个音色单独拎出来能听,但是合在一起
> 就在各唱各的戏的感觉。"
> 本文件是 v7 改造的依据,与 ARCHITECTURE.md 配套阅读。

---

## 1. 已解决的问题(前几轮)

- 音色闪现(钢琴 5%/吉他 15%)→ 角色化占比(钢琴 61%/吉他 67% 小节覆盖)
- 氛围层缺失(档1 只有鼓+贝斯)→ pad/弦乐档1 进场
- 转场生硬(先现+力度斜坡)→ 已缓解
- 声部半音摩擦(412→180 次)→ 刺刀降 5 度 + 音型随和弦

## 2. 仍存在的问题(本次诊断)

### 问题 A:所有层都踩在均匀网格上(节奏互锁缺失)
```
贝斯:   16分 █·█·█·█·█·█·█·█·   (重音 0/1.5/3.0)
吉他:    8分 █·█·█·█·          (3+3+2 重音 0/1.5/3.0 —— 与贝斯重音同拍!)
刺刀:    8分 █·█·█·█·          (0/0.5/1/1.5 —— 与吉他重叠区)
一提:   16分 █·█·█·█·          (与贝斯同网格)
```
**后果**:所有层的重音/音符在同一网格位对齐或重叠 → 听感是"齐奏的叠加"而非"交织的对话"。真正的乐队感 = 每层在别人空隙里呼吸(见 ARCHITECTURE §2A 互锁表)。

### 问题 B:音区重叠(旋律层互抢声场)
```
吉他 Hook:  69-83(高区)
一提音型:   74-79(与吉他重叠!)  ← 两个旋律性声部在同一音区同时发声
钢琴:       40-52(与贝斯高把位 43-50 重叠,但齐奏可接受)
```
**后果**:吉他 Hook 与一提音型同音区同时响,听感是两个旋律打架 → "各唱各的戏"最直接的来源。
**修复**:一提音型降 8 度(64-71),做"回声"角色(见 ARCHITECTURE §2B)。

### 问题 C:动机无对话(旋律层互不呼应)
```
当前:吉他 Hook(4 小节) 与 一提音型(16 分循环) 与 刺刀(8 分循环) 各播各的
修复:对话链(见 ARCHITECTURE §2C):
  吉他句头 → 一提回声(延迟 0.25 拍)→ 刺刀插入 → 贝斯高把位应答 → 齐奏收束
```

### 问题 D:密度断崖(档3 → 持续段)
```
档3:11 层全开,16 分驱动
持续段:吉他只剩 2 个刺点 + 钢琴轻击 —— 掉到 6 层且无驱动
```
**后果**:持续段"空"的感觉。用户要求"超级高密度"——持续段应保持 8-9 层:
持续段 = 鼓(8分驱动)+ 贝斯(16分)+ 弦乐 + pad + 合唱 + 钢琴(每拍重击)+ 吉他(刺点)+ 一提(回声)。

### 问题 E:音轨数不足(层次感上限)
```
当前 11 层:鼓/贝斯/一提/二提/中提/大提/吉他/铜管/钢琴/pad/合唱
缺:节奏吉他(档3 的 8 分切分和声)、riser/FX 音色(转场)、军鼓边击(16分幽灵音)、
   八度叠置层(吉他/钢琴高八度)、第二打击乐(镲片滚奏)
目标 14-16 层:每层有明确空间(低/中低/中高/高/极高频)与节奏角色
```
